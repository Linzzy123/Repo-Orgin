The purpose of this repository is to demonstrate basic Git and GitHub operations and collaboration. 
The steps followed included creating a repository, creating and switching branches, adding and editing files using PyCharm, 
committing changes, pushing the branch to GitHub, and collaborating through pull requests. The two collaborators involved in this 
tutorial are Leyancy Headley and Nerissa John and Linzzy. 

Steps Followed

Installed Git and created a GitHub account.

Created and initialized a local repository.

Created a GitHub repository and added a collaborator.

Created a new branch named tutorial-branch.

Created a Python file named tutorial.py.

Added and committed the file with a descriptive commit message.

Pushed the new branch to GitHub.

Created a pull request and assigned a reviewer.

Had the collaborator review and approve the pull request.

Merged the approved branch into the main branch.
